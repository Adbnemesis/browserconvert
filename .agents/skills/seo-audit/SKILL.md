# SEO Audit Router

Choose the audit workflow suited for your task:

1. **`seo-audit-marketing`** (Corey Haines / Marketing Skills)
   - Best for: Technical SEO, crawlability, indexing failures, title tag audits, local SEO, rankings push (moving positions 8-20 to page 1), and AI writing detection.
   - Reference docs: `references/international-seo.md`, `references/local-seo.md`, `references/rankings-push.md`, `references/title-tags.md`.

2. **`seo-audit-anthropic`** (Anthropic Knowledge Work)
   - Best for: High-level strategic review, keyword opportunities, content gap analysis vs competitors, and creating a prioritized executive action plan (quick wins vs strategic investments).

3. **`claude-seo`** (Agrici Daniel)
   - Best for: Full site audits, single-page deep dives, Core Web Vitals (INP), and structured data audits.
